# TrustIntern AI

A Blockchain-Based Internship Recommendation and Academic Credential Verification Platform.

## Directory Structure

- `db/`: Database schemas, scripts, and sample data.
- `backend/`: Spring Boot backend with Security, JWT, custom Blockchain, and JPA.
- `ai-service/`: Python service for Tesseract OCR certificate processing and TF-IDF Cosine Similarity recommendation engine.
- `frontend/`: React + Vite web application using Bootstrap and custom CSS.

## Getting Started

Follow the instructions in each sub-folder to run the components.
